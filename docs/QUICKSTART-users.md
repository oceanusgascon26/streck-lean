# Using Claude well: a one-page guide

Every message you send uses part of Streck's Claude budget. Longer chats, bigger files, stronger models, and more tools all use more. These habits get you the same quality answer for less.

## 1. Pick the right model

Click the model name next to the send button.

- Sonnet: the default. Use it for almost everything: email drafts, summaries, rewriting, questions about a document.
- Haiku: quick, simple jobs such as reformatting a list or fixing grammar.
- Opus: hard problems that need careful reasoning across a lot of material. Switch back to Sonnet when you are done.
- Effort (under the model name): leave it on the default or lower it for routine work. Higher effort takes longer and uses more.

## 2. Keep each chat to one task

The whole conversation counts every time you send a message, so a long chat gets more expensive as it goes. When you move to a new topic, start a new chat.

## 3. Start fresh with a summary

If a chat has run long and you still need to continue, ask Claude: "Summarize what we decided and what is still open." Copy the summary, start a new chat, and paste it in. You keep the important parts and drop the rest.

## 4. Use Projects for documents you use again and again

If you keep pasting the same policy, template, or reference file, put it in a Project instead. Project files are reused more cheaply than pasting them into each chat, and every chat in the Project can see them. Keep the Project instructions short.

You can also ask Claude to look up a past chat instead of explaining it again.

## 5. Attach only what is needed

Upload the pages or sections that matter, not the whole file. Bigger attachments use more, and a focused excerpt usually gets a sharper answer. Say which page or section to look at.

## 6. Turn off tools you are not using

Web search, Research, and connectors (such as mail or file storage) each add to what a chat uses. Turn them off for chats that do not need them. Use plain web search for a quick lookup, and save Research for a real research question. If you have many connectors, set Tool access to "On demand" (in the chat, "+" > Connectors > Tool access).

## 7. Ask for the size of answer you need

"In three bullets" or "one paragraph" gets you a shorter answer than an open question.
